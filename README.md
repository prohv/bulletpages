# BulletPages
Smart web page summarizing Chrome extension, working with Gemini API

## Description
BulletPages is a Chrome extension that summarizes web pages using the Gemini API. It extracts the main content from articles and generates concise bullet-point summaries.

## Installation
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked" and select the Bulletpages folder

## Setup
1. Click on the BulletPages extension icon in the toolbar
2. Click the "Gemini API key" button
3. Enter your Gemini API key (get one from https://aistudio.google.com/)
4. Click "Save API Key"

## Usage
1. Navigate to a readable webpage (like a news article)
2. Click the BulletPages extension icon in the toolbar
3. Select a summary type (4 points or 10 points)
4. Wait for the summary to be generated and displayed

## Troubleshooting
- If the page is not readable, you'll see a message indicating so
- If the summary doesn't generate, check that your API key is valid
- Make sure you're on a page with substantial text content
